Kira Live2D 远程壳（Windows 64 位）

1. 在运行 KiraAI 的电脑上打开插件设置，开启“远程壳模式”并保存。
2. 将本压缩包复制到另一台电脑，完整解压，双击 start.cmd。
3. 首次运行会从 Python 官方、PyPA 和 PyPI 下载独立 Python 与渲染组件，不需要安装 KiraAI。
4. 填写插件设置页的连接地址和访问密钥。地址使用 KiraAI 电脑的局域网／VPN IP，默认端口 18765，两端需网络可达。
5. 模型及资源自动同步，配置沿用插件；切换模型或重载后重新同步。模型和文本框位置保存在远程电脑。
6. 在远程壳连接窗口或模型右键菜单打开输入窗口，聊天与互动回到 KiraAI 当前桌宠会话。
7. 同时只允许一个远程壳。访问密钥可控制该桌宠，请仅交给自己的客户端。公网连接请使用 VPN 或 HTTPS 反向代理。

屏幕工具仍读取 KiraAI 所在电脑的屏幕，当前不读取远程电脑屏幕。
第三方组件说明见 THIRD_PARTY.md。客户端数据位于 %LOCALAPPDATA%\KiraLive2DRemote。
