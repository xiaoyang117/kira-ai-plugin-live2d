拖入模型文件夹、ZIP、LPK 或 WPK

普通模型需包含完整资源；LPK / WPK 自动解包，创意工坊 LPK 请连同 config.json 一起导入。支持 Cubism 3，最大 512 MB。

保留已使用和已导入的模型。选择后自动切换，已启用的壳会重新加载并更新状态；“不启动”模式仅保存模型。表情、动作、互动、换装及位置大小随模型保存。导入不会修改原文件。

资源提示

默认不启动，请在页面顶部选择连接模式；选择后立即应用并保存，下次启动沿用所选模式。本机桌宠支持 Cubism 3 JSON 模型，透明处自动穿透到下面的窗口；右键或系统托盘可打开调试面板。

动作 Agent 每轮上限

决策步数包含查看资源、动作、表情和结束步骤。上限越高，可能使用更多模型请求。短期上下文直接读取当前 KiraAI 会话，跟随 KiraAI 的记忆长度和清理结果；不会另设固定 8 条限制。

自动读取动作声明与目录中的 motion3.json，分析名称、时长及参数曲线。映射表会显示用途建议，不修改手填名称；这些建议不代表已视觉验证。新资源可用“重新识别模型”读取。

远程壳连接

在页面顶部选择“远程壳”后，本机只运行 KiraAI，桌宠由 Windows 独立壳或安卓 App 显示。模型与互动配置自动同步；同一时间只接入一个远程壳。

Windows：将远程壳解压后运行 start.cmd，首次自动准备组件。安卓：安装并打开 App。按页面顶部的说明填写连接地址，并使用下方的访问密钥。屏幕工具仍读取 KiraAI 所在电脑的屏幕。

手动换装

选入用于换衣服的表情或动作，可组合使用。保存后，桌面输入框的“更换”和 AI 都可选择这些可用项目。手动换装事件由你填写，留空或测试模式不触发回复。换装参数由原生壳保持，按模型分别保存。

模型映射与触摸区域

自动读取普通 JSON 的表情、动作和点击区域。直接编辑 AI 使用的名称；触摸部位由你填写。修改后保存，或恢复自动识别。

关闭整类开关，或取消表格中某项的“可用”勾选，可阻止 AI 和测试调用。保存后按模型生效；禁用项仍显示在表中，方便重新开启。全部关闭时正常聊天，不再要求附带表情或动作。

点击区域 → 身体部位

自动列出模型声明、点击动作组推断和实际收到的区域名，由你手填具体部位，如头部、左手或裙摆。动作组推断项需实际点击确认；留空时按普通点击处理。填写后保存生效。

拖动事件 → AI 感知

原生壳直接读取模型拖动声明，保留参数互动。填写各阶段发生了什么，留空不触发 AI；调试面板可核对拖动区域。未声明拖动控制器的模型不会凭空生成拖动项。
